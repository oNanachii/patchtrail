# PatchTrail简历项目条目

2026年10月28日。以下为两个岗位方向的候选写法，共用同一项目事实，按投递岗位选择其中一版。现有简历未修改；本人解释与关键修改验收仍待完成。

**项目名称：** PatchTrail 受控仓库排错与补丁验证工作台

**时间与角色：** 2026.10｜个人项目｜AI协作研发

## Agent与Python后端方向

技术栈：Python、FastAPI、SQLite、DeepSeek API、Podman。

- 借助AI开发受控排错工作台，接入DeepSeek工具调用，串联源码读取、失败复现、单文件补丁提案与确认后验证。
- 使用FastAPI与SQLite记录任务状态、事件和检查点，结合幂等键、哈希与版本校验，支持重复请求核对、补丁审批和中断恢复。
- 通过rootless Podman限制检查任务的网络、权限和资源；首轮3个已知回归任务经真实模型提案与确认后，修复后的12条用例通过。

## 前端与全栈方向

技术栈：React 19、TypeScript、Vite、FastAPI、SQLite、DeepSeek API。

- AI协作实现React与TypeScript前端及FastAPI同源接口，提供任务选择、运行阶段、补丁diff审阅、版本确认与JSON报告下载。
- 处理创建响应丢失后的同键核对、内存令牌和审批快照；清理失效鉴权下的缓存，区分脚本演示、真实调用、检查失败与结果未确认。
- 将构建产物与后端部署到独立HTTPS入口，提供GitHub源码；通过Chromium桌面与390px模拟视口复核实际结果、Podman脚本流程和报告下载。
