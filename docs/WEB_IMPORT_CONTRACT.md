# 网页导入与真实调用使用约定

用户反馈CLI过于麻烦后，本轮新增仅操作者可用的网页源码导入，保留CLI兼容。目标流程为载入操作令牌、选择项目文件、填写问题并检查可改源码、上传预览、确认导入、选择DeepSeek真实调用。导入本身不执行源码或调用模型。

## 导入边界

- 浏览器只发送操作者明确选中的UTF-8文本文件，不支持ZIP、Git URL、任意shell或镜像。尽量自动识别Python源码、测试及推荐profile，用户不必手写manifest。
- 文件限制沿用200个、2MiB总量、每文件128KiB；现有路径、隐藏/敏感文件名、测试和配置不可改、最多三个可改源码限制由服务器再次验证。文件名排除不等于检测所有硬编码秘密，上传前显示清单。
- 新POST预览路由允许最多4MiB JSON控制包装，服务器在读取body之前验证操作令牌；其它控制消息仍限制4096字节。不支持压缩或归档展开。
- 预览保存到私有、有数量/大小/过期界限的不可变暂存目录；响应只返回文件清单、大小和hash等元信息，不回显完整源码或服务器绝对路径。
- commit必须针对原预览身份，内容漂移拒绝。重复确认同一预览得到同一私有task；丢失确认响应时沿同一身份核对，不自动创建另一份运行。预览和确认都不能创建付费模型请求。
- 操作令牌清除或更换时，前端私有文件/预览/任务立即隐藏，旧文件读取、上传或确认响应不能回写新会话。编辑问题或文件选择后旧预览失效。

## DeepSeek真实调用

服务器已配置的DEEPSEEK_API_KEY由后端使用，网页不接收或保存该Key。网页载入的是独立PATCHTRAIL_ADMIN_TOKEN；令牌只留本页内存，经HTTPS同源Authorization头发送。

导入成功后选择相应私有任务，选“DeepSeek真实调用”，点击“开始真实调用”并确认费用，服务才调用模型。模型提出补丁后暂停，操作者审阅，再按准确digest/version确认容器验证。仅导入或选择模式不计模型费用。

当前固定执行环境支持Python标准库及已准备的pytest；不在任务中自动安装第三方依赖。缺环境、零测试、超时、截断、原始测试已通过等结果必须明确显示，不当作模型修复成功。

## 本轮验证

新增上传使用自编小型Python文件做权限、限额、幂等与实际浏览器验收，不为界面测试增加真实模型调用。既有真实DeepSeek案例及全部失败/拒绝继续保留，不能把新导入UI验证记成新的模型能力成绩。
