# 网页导入教学例子

`web-import-quickstart/`是明确自编的最小练习，源码故意把加法写成减法，测试保持只读；不是未知任务或真实业务效果证据。

在网页载入操作令牌后，选择这个文件夹（或其中两个Python文件），问题填写“add错误地执行减法，请修复加法，保留正数、负数及零的测试”，核对测试入口和允许修改的calculator.py后，上传预览并确认。

导入不执行源码、不调用模型。只有另行开始真实调用并确认费用后，才会向服务器配置的DeepSeek发送任务内容。不要为阅读讲解自动启动付费模型。

本例未在宿主机执行，也未在本轮交付中做付费修复；它用于让使用者自行操作熟悉流程。完整步骤见[项目讲解](../docs/PROJECT_EXPLANATION.md)。
